V-ARCHIVE Viewer for Windows

Run v-archive-viewer.exe from a writable folder.
The app stores settings and record history on this computer.
account.txt credentials are read locally and are never sent to the distribution server.

If the app cannot open after an update, run v-archive-repair.bat.
Option 1 clears only UI caches and preserves settings and History.
Option 2 verifies and reinstalls the latest release, then restarts the app.
