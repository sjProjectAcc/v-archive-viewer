V-LOG 도움말

V-ARCHIVE 기록을 내 기기에서 조회·분석하고, 표와 그래프로 정리하는 도구입니다.

1. 시작하기

닉네임을 입력하고 새로고침을 누르면 4B·5B·6B·8B 기록을 불러옵니다. 최근 조회한 닉네임은 입력란 아래에 저장되어 다시 클릭할 수 있습니다.

  • 지원되는 모바일 브라우저에서는 앱 설치 버튼이나 홈 화면에 추가 기능으로 PWA를 설치할 수 있습니다.
  • 상단의 버튼·패턴·검색 조건은 현재 탭의 표와 그래프에 공통 적용됩니다.
  • 표시 개수는 긴 표와 LogPower 순위의 출력 범위를 조절합니다.
  • F5는 화면만 다시 그리는 것이 아니라 일반 새로고침과 같은 데이터 갱신을 실행합니다.

2. 데이터와 캐시

기록은 브라우저 또는 데스크톱 앱이 V-ARCHIVE API에 직접 요청합니다. 별도의 중계 서버에 계정 기록을 저장하지 않습니다.

  • 프로필과 마지막 수집 시점은 IndexedDB에 저장됩니다.
  • 필터·그래프 범위·테마·최근 닉네임은 localStorage에 저장됩니다.
  • 일반판과 TEST 앱은 서로 다른 캐시를 사용하므로 같은 기기에서 별도로 시험할 수 있습니다.
  • 캐시는 다른 PC나 브라우저에 자동 동기화되지 않습니다.

3. 새로고침 방식

일반 새로고침은 마지막 수집 시점 이후의 변경분을 받아 기존 캐시에 합칩니다. 짧은 간격으로 눌러도 전체 기록을 매번 받지 않습니다.

  • 새로고침: 평소 사용하는 증분 갱신입니다.
  • 전체 새로고침: 캐시 누락·API 변경·데이터 불일치가 의심될 때 전체 기록을 다시 구성합니다.
  • API 오류가 난 버튼은 오류 수에 포함되며, 성공한 데이터까지 지우지는 않습니다.

4. 기록과 종합

기록 화면은 API의 원본 필드를 최대한 유지한 전체 기록표입니다. 숨겨진 열도 데이터에서 삭제된 것은 아닙니다.

  • 열 제목을 눌러 정렬하고 버튼·패턴·검색과 기록 전용 floor 범위를 함께 사용할 수 있습니다.
  • 종합 화면에는 수집 시점, 버튼별 기록 수, Tier, DJClass와 버튼별 LogPower Top50 합계가 표시됩니다.
  • 새로고침 오류가 있으면 종합 화면 아래쪽에 오류 기록이 추가로 나타납니다.
  • 최근 3일 이내 갱신된 곡명은 노란색으로 강조됩니다.

5. RATE

RATE 화면에서 LogPower, POINT, DJPower를 선택해 같은 필터와 표 구조로 확인할 수 있습니다. LogPower는 Score 97 초과 구간을 로그 함수로 0~10점으로 바꾼 뒤 floor 난이도 상수와 버튼별 정규화 상수를 곱합니다. 99.9 이상은 동일한 만점으로 처리합니다.

scorePoint = -loga((100 - min(score, 99.9)) / 3)
LogPower = scorePoint × floor 상수 × 버튼 정규화

  • 각 버튼의 이론상 LogPower 상위 50개 합계는 5000입니다.
  • RATE의 DJPower는 버튼별 베이직 상위 70개와 뉴탭 상위 30개를 따로 선발합니다.
  • DJPower는 V-ARCHIVE API 값을 우선 사용하며, 이론상 TOP100 합계가 10000이 되도록 버튼별 상수를 곱합니다.
  • 계산기에서 LogPower와 DJPower 모드를 바꾸어 정방향 계산과 목표 Score 역산을 할 수 있습니다.

6. Floor 분석과 산포도

Floor 분석은 선택한 floor 범위에서 내 최고·최저 기록과 기록 수, 전체 패턴 수, 달성률, 평균, 표준편차, floorMax를 한 줄씩 정리합니다.

  • 시작 floor가 끝 floor보다 크면 내림차순으로 출력합니다.
  • 산포도는 Score·scorePoint·LogPower·Point·DJPower 중 지표를 선택할 수 있습니다.
  • Point와 LogPower에서는 버튼별 TOP50 패턴을 별도 색으로 강조합니다.
  • 점에 마우스를 올리면 곡명, 패턴, 레벨, 점수와 지표값이 표시됩니다.

7. 곡 태그

곡 태그는 816곡의 BPM, 장르, 별칭과 채보 특성 태그를 곡 번호로 결합해 탐색합니다. 로페봇 전체 데이터와 행이봇 SC 데이터는 V-LOG가 제공하는 버전형 공용 파일을 받아 기기에 캐시합니다.

  • 공용 manifest의 데이터 버전이 바뀐 경우에만 새 태그 파일을 내려받습니다.
  • 패턴 태그만은 기본 선택되며, 버튼이 전체이면 모든 버튼의 패턴 태그를 함께 표시합니다.
  • 버튼을 고르면 해당 버튼의 패턴 태그로 범위가 좁아지고, 체크를 해제하면 공통 태그도 볼 수 있습니다.
  • SC 패턴만을 선택하면 _NM·_HD·_MX 태그를 숨깁니다.
  • 여러 태그를 선택해 모두 포함(AND) 또는 하나 이상(OR)으로 조합할 수 있습니다.
  • 장르, BPM 범위, 내 기록 유무와 서열표 기준 난이도 정렬을 함께 사용할 수 있습니다.
  • 공용 파일을 받을 수 없으면 저장된 캐시를 유지하고 기존 API 방식을 예비 경로로 사용합니다.

8. 성장 기록과 시점 비교

성장 기록은 V-ARCHIVE의 패턴별 변경 이력을 로컬 캐시에 수집해 시간에 따른 LogPower, POINT, DJPower 변화를 복원합니다.

  • 데스크톱 앱에서 V-ARCHIVE 앱 폴더의 account.txt를 지정하거나 회원 번호와 토큰을 입력해야 합니다.
  • 수집 간격은 응답 시간에 맞춰 자동 조정되며 실패와 429 응답에는 추가 대기 시간이 적용됩니다.
  • 그래프는 다음 기록까지 이전 값을 유지하는 계단형이며, 1분·1시간·1일 안의 인접 변화를 하나로 결합해 볼 수 있습니다. 원본 캐시는 바뀌지 않습니다.
  • 로컬에 프로필과 히스토리가 저장된 다른 닉네임을 선택하면 두 성장 그래프를 함께 비교할 수 있습니다.
  • 다른 닉네임을 조회하면 계정 연결은 해제되어 잘못된 계정 이력 수집을 막습니다.
  • 시점 비교는 두 시점 이전의 마지막 기록이 모두 있는 패턴만 비교합니다. 비교 시점을 비우면 현재 API 기록을 사용합니다.

9. 최근 성과 카드

수집한 성장 기록의 연속된 두 기록을 비교해 최근 갱신 순으로 성과를 선택하고 PNG 이미지로 출력합니다.

  • 점수 상승 또는 새 MAX COMBO 달성을 하나의 성과로 표시합니다.
  • 목록을 드래그해 여러 성과를 연속 선택하거나, 최근 시간과 LogPower 상승량으로 자동 선택할 수 있습니다.
  • 이미지 카드는 위쪽 곡 정보와 아래쪽 이전·현재 기록으로 구성되며 Score, scorePoint, LogPower를 비교합니다.
  • 가로 열 수를 지정하고, 이미지 머리말에서 닉네임과 선택 버튼의 Tier·DJClass·LogPower Top50을 확인할 수 있습니다.

10. 사용자 비교

사용자 비교는 두 계정에 모두 존재하는 title·button·pattern 조합만 표시합니다. floor 범위를 바꾸면 공통 기록 수와 우위 통계도 함께 다시 계산됩니다.

  • 그래프 위에서 버튼별 LogPower TOP50, DJClass와 Tier를 먼저 비교할 수 있습니다.
  • 공통 기록은 Score·LogPower·Point 차이를 정렬하거나 우위 계정으로 필터링할 수 있습니다.
  • 차이-합 벡터 그래프의 스케일은 동일·평행사변형·개별 방식 중 선택할 수 있고, floor 중점선을 켜거나 끌 수 있습니다.
  • 점에 마우스를 올리면 정보를 확인하고, 우클릭하면 현재 계정쌍과 지표의 그래프에서 제외할 수 있습니다.

11. 실험실

floor 관계값 후보를 입력하면 현재 기록 전체의 LogPower와 버튼별 Top50 합계를 즉시 다시 계산합니다.

  • 산포도는 후보 관계값으로 계산한 내 개별 기록과 floor별 분포를 보여줍니다.
  • 단일 버튼을 선택하면 해당 버튼의 정규화가 반영된 floor 최대치선도 표시됩니다.
  • 실험실 값은 임시 계산이며 실제 점수제, 기록 캐시 또는 저장된 결과를 변경하지 않습니다.

12. 이미지 출력

RATE의 LogPower Top30, Floor 분석, 산포도, 사용자 비교, 성장 기록과 최근 성과를 PNG로 다운로드합니다. 지원되는 환경에서는 같은 이미지를 클립보드에도 복사합니다.

  • 자켓 이미지는 DJMAX.GG에서 사용자 기기가 직접 요청합니다.
  • 외부 이미지 서버가 응답하지 않으면 이미지 생성에서 해당 자켓이 비어 보일 수 있습니다.
  • 이미지에는 닉네임, 그래프 조건, 앱 버전과 생성 시점이 포함됩니다.

13. 데스크톱 앱과 업데이트

웹 버전은 일반 기록 조회와 분석에 사용할 수 있고, 데스크톱 앱은 CORS 제한 없이 History API와 계정 로그인을 사용할 수 있습니다.

  • 업데이트 확인은 GitHub Pages의 버전 정보만 읽습니다.
  • 새 버전이 있으면 GitHub Release의 Windows ZIP을 내려받아 앱을 교체합니다.
  • 업데이트가 보이지 않으면 수동 업데이트 확인을 누른 뒤 앱을 다시 시작해 보세요.

14. 개인정보와 문제 해결

회원 번호와 로그인 토큰은 V-ARCHIVE 로그인 및 History 요청에만 사용하며, 이 프로젝트의 별도 운영 서버로 전송하지 않습니다. 토큰이 들어 있는 파일은 공유하지 마세요.

  • 기록이 이상하면 먼저 일반 새로고침, 이후 전체 새로고침 순서로 확인합니다.
  • History가 비어 있으면 조회 닉네임과 연결 계정이 같은지 확인하고 전체 재수집을 실행합니다.
  • API 오류의 상세 내용은 종합 화면 아래쪽 오류 기록에서 확인합니다.
  • 필터가 예상과 다르면 버튼·패턴·검색·floor 범위를 전체로 되돌려 확인합니다.

TEST 변경사항

행이봇 태그

태그*행이봇은 선택한 버튼과 패턴의 전체 곡을 표시합니다. 내 기록이 없는 패턴도 포함하며, 버튼별로 서로 다른 trait 코드를 열로 구성하고 합계와 함께 정렬할 수 있습니다.

종합

종합 탭은 버튼·검색 필터와 무관하게 전체 버튼의 Tier와 DJClass를 보여줍니다. 새로고침 오류가 있으면 같은 탭의 오류 기록 영역에서 바로 확인할 수 있습니다.

비교 그래프

스케일 방식을 동일, 평행사변형, 개별 scale 중에서 고를 수 있습니다. floor 중점선도 켜고 끌 수 있습니다.

POINT

버튼별 rating 순위와 maxrating, 달성률을 확인합니다. Tier에 반영되는 Rating TOP50 합계도 함께 표시합니다.

점 제외

비교 그래프의 점을 클릭하면 해당 곡을 현재 계정쌍·지표 그래프에서 제외할 수 있습니다. 제외 초기화 버튼으로 되돌릴 수 있습니다.
