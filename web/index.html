V-ARCHIVE Viewer README

기록을 로컬에서 조회·분석하고 이미지나 표로 정리하는 도구입니다.

데이터와 캐시

기록 데이터는 사용자의 브라우저 또는 앱에서 V-ARCHIVE API로 직접 요청합니다. 프로필과 설정, 히스토리는 사용자 기기의 IndexedDB와 localStorage에 저장됩니다.

새로고침

일반 새로고침은 마지막 수집 시점 이후의 변경 기록을 요청합니다. 전체 새로고침은 캐시 오류나 누락이 의심될 때 전체 기록을 다시 요청합니다.

LogPower

97점 초과 구간을 로그 함수로 0~10점으로 바꾸고 floor 상수를 곱합니다. 버튼별 이론상 Top50 합계가 5000이 되도록 정규화합니다.

History와 시점 비교

데스크톱 앱에서 account.txt로 계정을 연결한 뒤 기록 변경 이력을 수집합니다. 시점 비교는 각 시점 이전의 마지막 기록을 복원하여 같은 패턴끼리 비교합니다.

Compare

두 계정에 공통으로 존재하는 기록만 비교합니다. score, floor 분포의 표준점수, LogPower, Point 차이를 표와 산포도로 확인할 수 있습니다.

Debug

floor 관계값을 임시로 바꿔 현재 기록의 LogPower를 다시 계산합니다. 시뮬레이션 값은 설정이나 실제 기록에 적용되지 않습니다.

이미지 출력

LogPower Top30, Floor_View, 산포도, 비교 그래프, 히스토리 그래프를 PNG로 저장하며 지원되는 환경에서는 클립보드에도 복사합니다.

업데이트와 개인정보

앱은 GitHub Pages의 버전 정보만 확인하고 GitHub Release에서 ZIP을 내려받습니다. 회원 번호와 로그인 토큰은 V-ARCHIVE 요청에만 사용하며 별도 운영 서버로 전송하지 않습니다.
